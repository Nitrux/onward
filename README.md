# Onward | [![License](https://img.shields.io/badge/License-BSD_3--Clause-blue.svg)](https://opensource.org/licenses/BSD-3-Clause)

A getting-started guide for **[Nitrux](https://nxos.org/)**.

# Introduction

Onward introduces the Nitrux workspace and explains how to use its software tools and system design.

Onward is built with **[MauiKit](https://mauikit.org/)**.

## Features

- Nitrux workspace:
  - Learn common Hyprland shortcuts from Nitrux’s default configuration
  - Launch common applications and move between workspaces

- Software management:
  - Understand NX AppHub and AppBoxes
  - Learn how Nitrux uses Flatpak and Distrobox
  - Find software workflows in AppFinder

- System architecture:
  - Understand the immutable system base and Nitrux updates
  - Learn about OpenRC and Aesthetic FHS

## Requirements

- Nitrux.

### Runtime Requirements

- MauiKit 4.0.5 or newer
- Qt 6.9 or newer
- KDE Frameworks 6.13 or newer

# Usage

Launch Onward from the applications menu.
